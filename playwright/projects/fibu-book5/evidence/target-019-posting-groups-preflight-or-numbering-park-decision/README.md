# TARGET-019 Posting Groups Preflight or Numbering Park Decision

Instanz: playthru
Company: UNIVERSAARL-DE

## Entscheidung

Die offenen Nummerierungsfelder werden nicht als geloest behandelt. `U-CUST` und `U-ITEM` bleiben geparkt, `U-PO` bleibt nur eine sichtbare Kandidatenroute. Der naechste sinnvolle Foundation-Schritt ist ein read-only Posting-Groups-Preflight.

## Warum

Buchungsgruppen sind eine eigene Voraussetzung fuer Stammdaten, Preview Posting und spaetere Buchungen. Sie koennen gelesen werden, ohne Nummerierungswerte weiter zu veraendern oder erneut blinde Feldrouten zu testen.

## Grenzen

- Keine Setup-Aenderung.
- Keine Stammdaten.
- Kein Belegentwurf.
- Keine Preview und keine Buchung.
- Keine rechtliche Nummerierungs- oder USt-Behauptung.
