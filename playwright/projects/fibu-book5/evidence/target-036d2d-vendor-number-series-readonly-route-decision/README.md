# TARGET-036D2D Vendor Number Series Read-only Route Decision

Status: observed
Instanz: playthru
Company: UNIVERSAARL-DE

## Entscheidung

Der naechste praktische Schritt ist kein Kreditor-Retry. Zuerst wird U-VEND als Nummernserie fuer manuelle Kreditorennummern vorbereitet, weil der erste Lieferant als lesbarer Code U-VEND-100 geplant ist.

## Quellen- und Evidence-Basis

- TARGET-036D2C zeigt Page 456 / Table 308 und die Felder Default Nos. und Manual Nos. fuer U-VEND.
- Microsoft Learn beschreibt Manual Nos. als Weg, Nummern manuell einzugeben.
- Microsoft Learn beschreibt Default Nos. als Weg fuer automatische Nummernvergabe.

## Grenze

D2D hat nichts in Business Central geaendert. Manual Nos. ist noch nicht aktiv. Standard Nos. bleibt eine spaetere separate Entscheidung.
