# Risk Notes

- Eine Profilanpassung kann mehrere User betreffen.
- Eine User-Personalisierung kann Schulungsscreenshots von der Standardansicht entfernen.
- Production bleibt read-only, solange keine explizite Freigabe fuer Layoutaenderungen vorliegt.
- Screenshots koennen Kundendaten im Verkaufsauftrag zeigen und muessen anonymisiert werden.
