# Lessons Learned

- Posting-Setup-Fehler sind oft Schutzmechanismen, keine Bedienfehler.
- Eine Fehlermeldung mit konkreter Setup-Kombination ist ein Diagnosepfad.
- Ein Konto darf nicht geraten werden, nur damit Preview Posting weiterlaeuft.
- Regression muss den alten Fehlertext negativ pruefen und ohne separates Gate nicht buchen.
