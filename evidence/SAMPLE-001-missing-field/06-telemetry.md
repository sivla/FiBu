# Telemetry

## Erwartung

Fuer diesen Demo-Fall ist Telemetry wahrscheinlich nicht die erste Quelle, weil keine technische Fehlermeldung oder Exception gemeldet wurde.

## Wann Telemetry relevant wird

Telemetry wird relevant, wenn:

- Page langsam laedt
- Personalisieren Fehler wirft
- eine Extension die Page veraendert
- ein Permission Error im Hintergrund auftritt
- die Sales Order Page Exceptions erzeugt

| Merkmal | Wert |
|---|---|
| Zeitpunkt | nicht vorhanden |
| User | anonymisiert |
| Environment | unbekannt |
| Company | unbekannt |
| Operation | Sales Order Page anzeigen |
| Error Message | keine gemeldet |
| Object Type / Object ID | nicht belegt |
| Extension | unbekannt |
| Correlation ID | nicht vorhanden |
