# Known Issues Template

## Ziel

Dieses Template sammelt wiederkehrende Kundenprobleme, Workarounds und belegte Ursachen. Es ist kein Ersatz fuer Evidence, aber beschleunigt die Triage.

## Bekannte Issues

| Issue-ID | Kurzbeschreibung | Problemklasse | Betroffene Prozesse | Erkennungsmerkmale | Status | Evidence |
|---|---|---|---|---|---|---|
|  |  | Bedienhilfe / Setup / Bug / Standardgrenze / Berechtigung / Daten / Integration |  |  | offen / bestaetigt / geloest |  |

## Wiederverwendbare Regeln

- Wenn Symptom wiederkehrt, zuerst Known Issue abgleichen.
- Wenn Abweichung vorliegt, neue Hypothese statt alte Ursache blind uebernehmen.
- Jede geloeste Ursache braucht Evidence und Regressionstest oder Testplan.
