# TARGET-022 Dimension Value Setup Fit Decision

Instanz: playthru
Company: UNIVERSAARL-DE

## Ergebnis

TARGET-022 entscheidet ohne Business-Central-Aktion, dass vor Stammdaten zuerst ein kontrollierter Dimension-Setup-Fit sinnvoll ist.

## Gewaehlte Dimensionen

- PRODUCTLINE: SOFTWARE, SERVICE, TRAINING
- COSTCENTER: ADMIN, SALES, OPERATIONS
- CHANNEL: DIRECT, PARTNER

## Grenzen

- Keine Dimension wurde angelegt oder geaendert.
- Keine globale Dimension wurde gesetzt.
- Keine Standarddimension wurde zugeordnet.
- Keine Stammdaten, keine Belege, keine Preview und keine Buchung.
