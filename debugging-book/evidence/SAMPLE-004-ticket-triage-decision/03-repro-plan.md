# repro plan

1. Tickettext auswerten und Problemklasse vorlaeufig bestimmen.
2. Kundenkontext laden: Prozesse, Permission Model, Known Issues, Extensions.
3. Environment, Company, User/Rolle und genaue Fehlermeldung erfragen.
4. Safe Action Policy pruefen: keine Buchung, keine Rechteaenderung, keine Setup-Aenderung.
5. UI Evidence read-only planen: Page, Aktion, sichtbarer Fehler.
6. Data Evidence read-only planen: Permission Sets, Effective Permissions, Setup.
7. Telemetry Query vorbereiten, aber nicht live ausfuehren.
8. Erst danach entscheiden: Bedienhilfe, Setup, Bug, Standardgrenze oder Rueckfrage.
