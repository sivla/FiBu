# Posting Skill

Use for: Preview Posting, kontrollierte Buchung und Postenspur.

Do not use for: Mini-Gates ohne Setup-/Preflight-/Trace-Plan.

Inputs: Source Document, erwartete Buchungsoption, erwartete Postenarten, Cleanup-/Keep-Strategie.

Outputs: Preview-Arten, Buchungsdialog, gebuchter Beleg, Ledger Trace.

Safety: Posting ist default-locked und braucht aktiven Case-Unlock.
